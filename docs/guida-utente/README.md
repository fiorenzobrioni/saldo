# Guida utente

Manuale d'uso di Saldo, una pagina per funzionalità. Spiega cosa fa ogni opzione e cosa aspettarsi, dal punto di vista di chi usa l'app (non del codice).

Il manuale cresce in modo incrementale: ogni volta che una funzionalità viene aggiunta o cambia in modo visibile all'utente, si aggiorna o si aggiunge la pagina corrispondente.

## Indice

- [Movimenti ricorrenti](movimenti-ricorrenti.md): uscite, entrate e trasferimenti che si ripetono nel tempo, con registrazione automatica o con conferma.
